# Roblox Development

A collaborative case study about reusable Roblox game systems and asset packs built by a small studio.

## The project

The team built reusable game templates to help creators launch Roblox experiences more quickly. I helped lead a three-person coding team within a five-person studio.

## My contribution

I co-developed systems in Luau with the team, including player-data persistence, NPC placement and collection, reusable user interfaces, and mobile controls. I also helped plan features, debug issues, test behavior, and coordinate the coding team.

The work was collaborative. The exact division of code ownership and which individual systems shipped should be confirmed before adding code samples.

## Results

- Released games using the team’s templates reached 258.6K peak concurrent players and 1.5B+ combined visits.
- We also co-created Roblox asset packs with 100+ paid team sales.
- Games using those packs reported 330K+ combined concurrent players.

The template metrics and asset-pack metrics describe different groups of games. They are team and downstream results, not a claim that I built or operated every finished game.

## Technology

Luau, Roblox Studio, data persistence, NPC systems, reusable UI, and mobile controls.

## What I learned

Reusable systems need clear interfaces and steady testing across different gameplay flows. Team projects also depend on dividing work, communicating changes, and checking that shared systems fit together.
